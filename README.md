# jobbot

**Map-first job search CRM.** *I run my job search the way an AE runs a territory.*

**Live demo:** https://br0s1-cloud.github.io/jobbot/ (sample data: real companies; contacts are nameless role placeholders)

Every target company's offices sit on a map, sized by open roles and colored by how far each application has gotten. The pipeline is pinned down the right side: drag a card to a new stage and its pin changes color. Switch between DC, Austin, NYC and Seattle in one click.

Built with React, TypeScript, MapLibre, Firebase (Auth + Firestore), and GitHub Pages. Work in progress: Gmail ingestion, the relationship network layer, and interview tracking are next.
